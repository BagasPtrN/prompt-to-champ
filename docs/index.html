Kenapa dipakai di pelatihan

Belajar prompt AI sambil bermain

Dirancang untuk peserta pelatihan AI UMKM — termasuk yang kurang lancar mengetik: input utama tulis bebas, dengan chip bantuan frasa (gaya/cahaya/kamera/latar/font/mood) yang tinggal diketuk. Bahasa antarmuka Indonesia sehari-hari, tombol besar, alur ala game ponsel.

Server = sumber kebenaran (fase & timer) · Socket.IO realtime · reconnect token · mode juri host · bot uji otomatis · rekap & ZIP poster per room · API key OpenAI hanya di server (.env)

Versi multiplayer penuh

Jalankan sendiri di laptop + proyektor

Demo di halaman ini versi pemain-tunggal. Untuk party sungguhan 3–30 pemain, jalankan server Node.js-nya (gratis, provider gambar mock tanpa API key):

# butuh Node.js 18+
git clone https://github.com/BagasPtrN/prompt-to-champ
cd prompt-to-champ
npm install
npm start

# buka host di proyektor:
➜ http://localhost:3000  # scan QR / share tautan /IP:3000 ke pemain

# main sendiri tanpa nunggu pemain lain?
# di layar host, klik tombol:
🤖 + TAMBAH BOT  # ulangi sampai minimal 3 pemain — game langsung mulai!
# bot ikut menulis prompt & menilai poster seperti pemain sungguhan

Mau poster beneran dari AI? Salin .env.example jadi .env, isi OPENAI_API_KEY, ganti IMAGE_PROVIDER — kunci tidak pernah dikirim ke browser.
